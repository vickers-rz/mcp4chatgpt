## 阻断项

### A1 / P1：PDF 替换可能成功返回错误文字

位置：`src/mcp4chatgpt/pdf_ops.py:198-206`。

复现：创建 PDF，用 24pt Helvetica 写入 `OriginalLong`；调用 redact_text，将其替换为 `Ω`。函数返回成功，但重新打开输出 PDF 提取文字得到 `?\n`，没有 `Ω`。同样条件替换成 `é` 或 `OK` 正常。

原因：Font.has_glyph 的字体字形检测不能保证 insert_textbox 实际采用的编码能够写出该字符。当前验证只确认生成文件可打开。

通过条件：校验实际写入路径支持的编码，或使用能正确编码该文字的字体；不支持时拒绝发布。对成功输出重新提取文字，验证 Ω、Latin-1 和中文的明确支持/拒绝结果。

### A2 / P1：casefold 扩展字符被部分命中，扩大删除范围

位置：`src/mcp4chatgpt/pdf_ops.py:115-125`。

复现：PDF 仅含 `ß`，调用 redact_text(query="s", case_sensitive=False)。返回 matches=2，输出文字为空。一个原字符被计为两个命中并删除。

原因：ß.casefold() 是 ss；算法没有要求匹配起止位置对应完整原字符边界。对单个 s 的匹配无法准确定位到原 PDF 中的半个字符，却仍删除整个字形。

通过条件：仅接受落在完整原字符边界上的匹配，或对无法精确定位的命中明确拒绝；query="ss" 可以命中一个 ß，query="s" 不得报告两个可独立删除的命中。

### A3 / P2：CUA 非法 UTF-8 绕过协议错误和连接清理

位置：`src/mcp4chatgpt/computer_cua_backend.py:227-230`、`1109-1113`。

复现：在活跃受控 helper 的接收缓存放入字节 ff 0a，再调用 _read_message(.1)，实际抛 UnicodeDecodeError。这里只捕获 JSONDecodeError；外层 call 仅对 CUABackendError 清理连接。

通过条件：非法 UTF-8 归类为 cua_protocol_error；断开并清空受损会话。对已经发送的副作用请求保留 outcome_unknown，并验证不触发 native 重放。

### A4 / P2：状态查询没有核验进程出生身份

位置：`src/mcp4chatgpt/jobs/manager.py:80-94`。

复现：临时 JobStore 的 metadata 使用当前测试进程 PID，state=running，但 supervisor_identity 填为不同身份；_augment_status 返回 state=running、supervisor_alive=true、process_identity_verified=null。

原因：查询仅检查身份字段是否存在，没有与实际身份比较；取消路径的身份校验不能替代状态查询核验。

通过条件：恢复后身份不匹配或无法核验时明确返回 unknown；不得把复用 PID 对应的其他进程报告为原任务存活。保留正常查询、旧记录和取消路径回归。
